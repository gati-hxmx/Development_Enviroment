# タスク発掘（groom）

## 手順

1. `blocked` の Issue を確かめる。利用上限が戻っていれば `blocked` を外し、最後のコメントの「次に呼ぶスキル」から再開する。
2. `in-progress` のまま24時間以上動きがない Issue を探し、引き継ぎメモから再開するか、止まった理由を書く。
3. 次からタスクの候補を集める。
   - エラー監視で増えているエラー
   - main で不安定なテスト
   - コード中の TODO・FIXME
   - 遅い処理、古くなった依存
4. 重複を除き、価値が高いものから Issue を起こす（1日5件まで）。根拠（ログ・件数・該当箇所）を本文に書き、`agent` ラベルを付ける。
5. 何をしたかを通知する（`scripts/notify`。件数と Issue へのリンクだけ）。

## 次に呼ぶスキル

- 起こした Issue ごとに triage
