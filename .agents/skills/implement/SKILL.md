# 実装（implement）

## 手順

1. 最新の main から作業ブランチを作る（Claude は `claude/<Issue番号>-<短い名前>`、Codex は `codex/…`）。
2. 受け入れ条件ごとに、まず失敗するテストを書く。
3. テストが通る最小の実装をする。既存の構成・命名・共通部品に合わせる。
4. `scripts/check` を実行し、通るまで直す。
   - テストを消す・スキップする・期待値を実装に合わせて書き換えることはしない。
   - 同じ失敗で3回直せなければ、原因の仮説と試したことを書いて escalate する。
5. こまめにコミットする。コミットメッセージには何をなぜ変えたかを書く。
6. 仕様の変更が必要になったら、勝手に変えずに spec に戻る。
